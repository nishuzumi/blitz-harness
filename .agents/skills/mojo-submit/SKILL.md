# 提交到 MOJO

## 1. 准备

先按 `mojo` 技能（`.agents/skills/mojo/SKILL.md`）第 1、2 步找凭证、现读接口说明。

## 2. 先查再交

按接口说明「查看活动信息与现有项目」一节查询：

- 提交没开放：停下来告诉用户，不要硬试。
- 已经有项目：走「更新已有项目」，不要重复创建。
- 团队赛只有队长的 Agent 能提交，不是队长就告诉用户。

## 3. 一次问齐材料

需要：项目名、简介、演示链接、GitHub 地址、至少一张截图。
先从当前仓库里找（README、package.json、git remote、已有截图），找不到的一次性问用户，不要一项一项问。
把要提交的内容给用户过目，确认后再提交。

## 4. 提交

按接口说明的「上传项目截图」「创建参赛项目」或「更新已有项目」几节操作。
成功后告诉用户：项目进入 `pending`，等主办方人工审核，提交了不等于入选。
