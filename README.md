# Monad 黑客松 Harness

优先支持 Codex 的 Monad 黑客松作战模板。

目标：从项目想法到演示、提交材料、3 分钟路演，都知道下一步。

## 启动：直接说需求，Codex 自动选技能

无需安装，打开仓库直接用。

```text
我要参加 Monad 黑客松，帮我开始。
我现在应该做什么？
你能帮我做什么？
bash scripts/doctor.sh
```

未初始化时，泛化问题也会先触发 `m-start`。

## 流程

```text
开始
├─ 没想法：生成候选想法
└─ 有想法：整理想法
      ↓
    追问 → 计划 → 提交 → 路演
```

- 直接说你要做什么
- `m-router` 自动选择技能
- Monad 实现交给 monskill
